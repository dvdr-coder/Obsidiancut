Obsidian Cut — Full Codebase, Diagrams & Installation Guide

Obsidian Cut is a lightweight, high-performance multi-track NLE studio built with a React 19 + 2D Canvas + Web Audio frontend, an Express + Vite gateway (server.ts), and a zero-dependency Python + FFmpeg render engine (backend/engine.py). Explore every module, interactive signal-flow diagram, installation command, and REST API contract below.

01 / System Blueprint

End-to-End 3-Tier Architecture

How the browser editor, Express proxy gateway, Python FFmpeg worker, disk storage, and batch CLI communicate.

Dual-Path Proxy Strategy

Heavy 4K/VFR videos automatically generate lightweight 480p CFR H.264 proxies inside .obsidiancut_data/proxies/ for lag-free timeline scrubbing, while final exports always read the untouched master uploads in uploads/.

Zero-Bloat Low-Hardware Design

All audio waveforms, spectrum bars, keyframe splines, and color grades render directly on native HTML5 <canvas> elements with zero heavy WebGL/Electron runtime overhead.

Cross-Platform Supervision

server.ts auto-detects python3, python, or Windows py -3, spawns backend/engine.py on internal port 3001, and handles both POSIX SIGINT/SIGTERM and Windows SIGBREAK.

08 / Studio Modes & Controls

Four Specialized Workspaces & Shortcuts

All four modes operate over the same unified timeline state so switching between Quick Render, Endless Workspace, and Fairlight is seamless.

1. Auto Mode (Beat Sync)

Analyzes music tempo (BPM) and cut-points, then aligns photo/video cuts, Ken Burns motion, and transitions directly onto musical beats.

2. Endless Workspace

Stack unlimited Overlay (OL), Video (V), and Audio (A) tracks vertically with Rough Cut snap unlock, waveform volume draggers, and curved fade handles.

3. Advanced Mode

Houses four pro sub-studios: Fusion (Keyframes + Particles/Roto), Fairlight (Meters, RTA Spectrum, Crossfades, ADR), MultiMaster, and Transitions.

4. Quick Render Page

Streamlined export-first workspace with Auto-Select Everything (transitions, opacity fades, BGM looping/ducking), Audio Normalizer, and inline video playback.

09 / Installation & Deployment

Complete Installation Guide (All Platforms)

Requires Node.js 20+, Python 3.9+ (zero pip dependencies), and FFmpeg/FFprobe on PATH.

Environment Variables: Set OBSIDIANCUT_DATA_DIR to store uploads, proxies, and rendered exports on a larger SSD/drive, or PYTHON_BIN to target a specific Python 3 interpreter.

11 / Batch Video Automation

Declarative HJSON CLI (autoengine)

Render dozens of beat-synced or explicit multi-track timelines headlessly from a single human-readable .hjson manifest.

bash — CLI Batch Workflow 
# 1. Validate manifest paths & options
python3 -m autoengine validate autoengine/examples/batch_videos.hjson

# 2. Preview clip assembly without encoding
python3 -m autoengine run autoengine/examples/batch_videos.hjson --dry-run

# 3. Execute parallel FFmpeg renders with JSON report
python3 -m autoengine run autoengine/examples/batch_videos.hjson --workers 2 --report autoengine/output/batch_report.json
